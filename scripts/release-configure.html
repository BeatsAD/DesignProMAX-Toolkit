Configure DesignProMAX Toolkit

Create a Figma Design → Custom UI development plugin. Copy its numeric ID here. No Node.js or network request is needed.

在 Figma 创建 Design → Custom UI 开发插件，将模板 manifest.json 中的数字 ID 填入下方。本页面离线运行，不发送 ID。

Move the downloaded manifest.json into this extracted folder, replacing the unconfigured file. Then import that manifest in Figma desktop. Keep the folder in place.

将下载的 manifest.json 放回解压目录，替换未配置文件，再通过 Figma 桌面版“从 manifest 导入插件”。导入后不要移动目录。
