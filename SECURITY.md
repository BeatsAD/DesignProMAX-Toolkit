# Security reporting / 安全报告

Report suspected security or privacy vulnerabilities privately to **wenbinailab@gmail.com**. Include the source commit/plugin version, affected feature, impact, and reproduction using synthetic data.

Do not publish credentials, customer documents, exploitable private endpoints, or sensitive diagnostic material in public issues. Do not email real API keys either; redacted/synthetic examples are sufficient to begin triage.

The current 0.3.x line is a development preview. Fixes are evaluated against current source; no security-update support period, response deadline, or guaranteed resolution time is promised. External image services have separate security/privacy policies.

当前 0.3.x 为开发预览，问题针对当前源码评估；不承诺固定响应时间、修复时限或旧版本维护周期。
