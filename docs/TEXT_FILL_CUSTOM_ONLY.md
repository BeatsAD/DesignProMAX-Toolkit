# 文本填充仅保留自定义

2026-10-16，Figma v0.3.1。按用户最新确认实施，取代开发初期保留常用字段的方案。

## 当前行为

- 进入文本填充直接显示已保存的自定义字段，不再显示“常用字段／自定义”切换，也没有姓名、电话、供电单位、省市区、数字、日期、地址和公司预设。
- 保留新增、编辑、保存、删除与顺序、随机、循环、固定值四种填充方式，以及预览、勾选、确认执行和既有字体保护。
- 自定义字段的存储键、数据结构和既有内容不变。读取失败显示手动重试，禁止把读取失败当成空列表再保存；保存失败保留旧值与草稿。提示状态变化不再重新触发字段读取、重建编辑区或丢失焦点。修改配置或选区后，旧预览失效。
- 两条预览请求路径均使用仅支持自定义的主线程实现，旧预设字段请求被拒绝。内置样本、数字生成和日期生成退出正式构建。

## 资源与文件
