词典合并后从 1245 行变为 1250 行；本轮修订或新增 68 行有效词条，逐项差异保存在本机 `output/localization-review-20261017/translation-diff.json`。没有为修改文案新增运行时覆盖层；仍直接维护现有词典。日语统一“カスタムフィールド”，韩语统一“사용자 지정 필드”和“간편”模式名称。译文不改写用户名称、输入、密钥、字体名或识别结果。

## 重要修改对照

| 原表述或问题 | 当前表达与依据 |
| --- | --- |
| 清理帮助暗示实例内部对象可以明确选择后处理 | 明确“包含（仅预览）”，实例内部对象不能勾选或执行清理，与现有执行限制一致。 |
| OCR 只要求检查低置信度行 | 帮助要求逐行核对；识别结果始终提示高置信度也可能出错，使用前核对数字、日期、金额。 |
| OCR 低置信度提示由句子片段拼接 | 使用完整句子模板，各语言自行安排行号列表的位置；保留全部行号。 |
| 取消后的批量填充、替换、适配和图片结果仍可能显示“完成” | 在已有 cancelled 回执下显示“操作已停止”，保留成功、失败数并说明已完成修改保留。未改变执行、取消或撤销机制。 |
| 写入结果不明与刷新失败的提示不够明确 | 写入结果不明先检查画布，帮助明确不要直接重复写入；选区刷新失败重试的是读取，不重放写入。 |
| 公告仍称“仅在浏览器验收” | 改为当前工具用途和免费使用说明，保留外部服务收费与上传授权说明；公告 ID 不变，已确认状态不重置。 |
| 帮助仍提到已移除的素材功能与模型配置 | 移除无对应工具的资源分组，分类说明与当前功能一致；缓存说明列明实际保留项。 |
| 抠图卡片写“单图透明 PNG” | 改为“通过外部服务移除背景”，不把批量处理错误描述为仅支持单图。 |
| 自动识别按钮与帮助的外文名称不同 | 统一为当前界面的 Detect regions 及对应七语，帮助指向相同按钮。 |
| 0、1、多项共用复数数量句式 | 主要数量摘要改为“Selected objects: 1”“Recognition complete. Lines: 1”等标签与数量形式。 |
| 320px 帮助索引截断工具名 | 保留原参考样式基线，在 Figma 的窄窗口适配层允许名称换行，保留双列布局、字号和图标。 |
