# Figma 设计一致性修复记录

2026-10-16，v0.3.1。用户已授权执行同日设计审查方案。本轮修改限于 Figma 独立工程，未发布、推送或执行插件打包，版本不变。当前构建已按原脚本同步到本地注册开发插件。

## 实施范围

| 原审查项 | 实现 |
| --- | --- |
| 01 缩放热区与执行按钮重叠 | 完整窗口的滚动区域留出52px底部安全区。窗口手柄仍44×44；内容区域底部598px，手柄顶部606px。滚动中也不会在手柄下显示可操作内容。紧凑窗口没有手柄，保持原工具栏空间。 |
| 02 收起字段导致预览失效 | 配置签名将与已保存字段等价的草稿归一为空。展开、收起和重开不使结果失效；真实名称、候选值、顺序、填充方式或选区变化仍会使结果失效。 |
| 03 窄窗不能同屏比较前后结果 | 520px及以下使用前后对照卡片，521px起使用表格。仅挂载当前布局，避免重复渲染结果；切换时沿用原勾选状态和预览。 |
| 04 小字对比度 | 宿主品牌变量保持原映射，为主按钮、危险动作、提示和辅助文字派生可读性颜色；不覆盖禁用控件语义。实际颜色随宿主变量更新，无额外初始化扫描或网络请求。 |
| 05 执行按钮层级 | 执行填充、执行适配采用主操作样式；新增字段降低强调，清空/重置保持次操作，清理/覆盖保持危险语义。 |
| 06 提示与当前状态不一致 | 填充、拆合、替换、适配、清理统一使用 NoticeBar；预览失效时不再同时显示先前的结果成功提示。替换样式的扫描和错误也使用公共组件。 |
| 07 抠图前置条件 | 选图、服务、质量、凭证和上传许可未就绪时禁用执行；明确配置说明和“去配置”入口，不调用外部服务。 |
| 08 无效间距变量 | 定义缺失的 space-2，恢复返回箭头间距及窄屏表头间距。 |
| 09 空态过高 | 等待区保持约96px紧凑空态，结果按内容增长；宽表格仍保留必要的局部滚动和高度上限。统计结果缩小初始高度。 |
| 10 分组层次 | 保留4/8px基础，区块与面板内部使用12px；首页仍使用8px节奏。 |
| 11 文字角色 | 保留10/11/12px、450/550字重；重要字段标签采用正文颜色，提高辅助文字和占位文字可读性。确认框保持紧凑字号，增加内部留白。 |
| 12 返回与点击区域 | 设置子页明确显示“返回设置/返回常规设置”，帮助返回明确指向设置；顶部返回至少28px高。批量结果复选框保留14px图形，可通过28px标签区域点击。 |
| 13 状态色含义 | 已配置字段改为中性底色，保留配置状态点；深色选中图标使用选中前景色。 |
| 14 多语言与公开文案 | 补齐填充、合并/拆分预览的动态模板及新增文案的八语。完整系统句子通过公共提示组件翻译，图层名、字段名、前后内容保留用户原文；移除两个空态的“首版”措辞。 |
| 15 统计默认含义 | 显示“附加统计内容”，说明顶层画框默认统计；空态文案对应所选页面。 |
| 16 首页密度 | 保留横幅、公告、布局管理和用户排序，缩短宣传图显示高度；沿用原图片及延迟加载。 |

主要视觉规则集中于 `src/ui/design-consistency.css`；参考样式及 exactCopies 哈希不变。已授权修改的参考组件与页面，在 `mastergo-ui-baseline.json` 中记录原哈希及原因，没有更新 exactCopies 来绕过校验。没有增加UI库、字体文件、图片、模型或其他离线资源。

## 验证

- 类型检查、最新生产构建、静态八语审计通过：1242行词条、898条生产文案、0静态缺失。
- `node --test tests/*.check.mjs`：82项通过，包含6项生产启动集成检查。新增回归覆盖收起/展开保持预览、真实修改失效、动态文案保留用户名称，以及窄屏卡片和合并说明的实际翻译渲染。
- `node --test tests/plugin-startup-integration.check.mjs`：针对相同最终生产构建显式复核。属于同一6项检查，不另计为新功能覆盖。
- `npm run verify:isolation`：1685个构建输入均在独立工程内；参考样式基线通过。
- 浏览器384组几何布局：八语 × 320/380px × 明暗主题 × 首页、10个工具、常规设置。未发现页面横向溢出或按钮文字超出。后续颜色修正不改变这些布局参数；在最终颜色上另做计算样式复核。
- 填充结果48组：八语 × 320/380/820px × 明暗主题。预览未因折叠失效，窄窗使用3张卡片，宽窗使用1张表格，无重复挂载或内容横向溢出。
- 原点击复现路径：执行按钮与缩放手柄重叠面积0；按钮右侧命中执行按钮。真改候选内容时显示警告、禁用执行并移除旧成功提示。选中2项的确认数量为2，隔离示例写入成功2项。
- 紧凑窗口实测：带文字380×111、纯图标380×101；工具可展开至380×650，并恢复完整窗口。示例的工具栏文字偏好已恢复。

本机证据位于 `output/design-consistency-implementation/`：源码备份、前后哈希、测试日志、layout-matrix.json、result-matrix.json、colors.json、hit-test.json、compact.json及最终截图。截图和示例测试不替代真实Figma宿主验收；本轮未重新启动真实插件或修改实际设计图层，也未重新验证外部抠图服务、所有图片结果、全部替换子模式及真实冷启动耗时。
