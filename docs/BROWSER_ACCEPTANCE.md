## 用户验收重点

1. 对照 MasterGo 核对首页、侧栏、参数、结果表格、设置和窗口操作是否保持原样。
2. 切换右侧示例，体验原有“配置 → 预览 → 勾选 → 确认”流程及示例撤销。
3. 用自己的图片核对透明裁剪、分割边界及 OCR。
4. v0.3.1 已补齐全界面多语言，按最新多语言验收记录检查语言切换、保存和完整帮助。
5. 用户通过测试页后，再安装 Figma 验证真实宿主；外部抠图需用户自备密钥和上传许可，当前未向收费服务发送测试请求。
