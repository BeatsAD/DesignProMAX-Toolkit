# v0.3.1 多语言实现与验收

日期：2026-10-16。当前是本机浏览器验收版，未安装 Figma、未发布或推送。

## 已实现

- 支持 English、简体中文、日本語、한국어、Français、Deutsch、Español、Português。
- 启动先读取保存的语言。没有合法保存值时展示原风格语言选择框，默认英文；用户确认保存后才进入插件。已有保存值时直接沿用，不闪现首次选择框。
- 设置 → 常规设置可切换语言。保存成功后更新页面、日期日历和浏览器测试画布；保存失败保留旧语言并显示可重试的提示。
- 覆盖原版工具页面、参数、提示、错误、确认框、帮助、设置、消息中心、图片替代文本和无障碍标签。动态标签、数量和诊断状态支持模板。统计报告标题随语言变化。
- 首页沿用原按钮和画面比例，插画重新生成无文字版本，标题与说明由 HomeBanner 组件独立渲染并翻译，不再依赖遮字色块。原图仅作参考保留，详见 BANNER_ASSET.md。
- 图层名、文件名、页面名、用户输入、API Key、字体名称、OCR 结果以及中文填充数据保持原值；改变语言不翻译文档。日历使用 Intl，数据生成规则继续按用户选择执行。

2026-10-16 设置页批注修订：去掉语言下拉框重复标签与辅助说明，以及布局管理的总说明。保留语言标题、8 个选项、保存失败反馈和两个布局管理入口。浏览器中英切换及恢复中文已验证，记录为 `output/browser-test/settings-copy-review.json`。该次首屏由 1,159,884 降至 1,159,341 字节，资源加载时机未变。

最新默认窗口为 380×650；首页卡片按当前语言最长内容统一增高，较长内容通过面板纵向滚动查看。八语与 320/360/380/420px 的最新验收见 [380px 窗口适配](WINDOW_380.md)。此前 420px 窗口的历史记录保留在 `output/browser-test/`。

## 真实宿主初始化通信兼容修复

客户端已打开插件窗口，但停在 Loading language settings。代码分析与局部复现发现，旧消息桥无条件拒绝 source=null 的消息；尚未从真实客户端采集事件 source，因此不把这一兼容缺口直接宣称为已确认的原生故障根因。

修复允许父窗口和 source=null 中转回复，但都必须匹配本 UI 用 Web Crypto 生成的 128 位随机会话标记；RPC 还必须匹配未完成请求及严格的结果结构。主线程回传会话标记；UI_READY、会话消息、选区更新和 RPC 统一使用同一通道。仍拒绝其他窗口、无标记/错误标记、跨会话、未知请求、重复和迟到回复。

SETTINGS_READ 的等待上限由 60 秒缩至 10 秒，超时沿用八语错误与重新读取入口；不回退到默认设置，不清空保存语言。写入操作的等待上限没有缩短，避免以重试读取的方式重放写入。控制台仅记录读取发出、主线程收到、有效回复接受（含 sourceIsNull 布尔值）和超时，不记录会话标记、设置内容、密钥或文档数据。

新增 tests/native-bridge-roundtrip.check.mjs 将生产主线程构建与非预览 UI 桥连接，经 source=null 模拟中转验证首次读取/保存/重开、会话/选区、十秒超时/重试、迟到回复隔离及存储失败不写入。它使用存储和消息中转替身，仍不替代真实 Figma 宿主。npm run verify 的 53 项检查通过，日志 output/figma-language-bridge-fix.log。注册入口代码与 dist 逐字节一致；证据 output/figma-registration/language-bridge-fix.json。

本次首屏 1,159,787 → 1,160,325 字节（+538），完整 HTML 8,434,634 → 8,435,172，主线程 102,450 → 102,705。增长来自认证标记、统一消息校验及轻量启动日志，无新增依赖或素材。Banner、行政区、OCR 仍按原时机延后读取。父工程及其他平台 746 个原文件 SHA-256 一致。

## 顶层窗口回复修复与真实 Figma 验证

本轮直接控制 Figma 桌面端，临时监听只记录消息元数据，确认实际回复 origin=https://www.figma.com、source=window.top、source!=window.parent、source!=null，RPC_RESULT 的 ok=true 且含会话标记。设置读取已成功，旧来源判断在检查标记与请求 ID 前丢弃了该回复，导致十秒超时。临时监听已移除。

receiveHostMessage 增加严格来源域名匹配的 Figma 顶层窗口分支；父窗口和 null 中转分支保持原有认证要求。RPC、会话、选区共用此修复，不更改首开语言规则、已存设置或主线程存储。

新增多层 iframe 测试先在旧代码下失败，再在修复后通过。覆盖成功回复、错误域名（含后缀冒充域名与 HTTP）、错误标记、非待处理 ID、畸形结果及其他窗口；生产主线程/UI 桥首读、保存、重开、会话和选区分别通过 null 与 top 传输。npm run verify 共 55 项通过，日志 output/figma-top-window-fix.log。

真实 Figma 验证：首次显示八语弹窗，English 默认选中；确认后进入插件正文，关闭首次公告后显示十个工具的首页；设置页可以保存简体中文，完全关闭再从 Development 菜单打开，直接显示中文首页，没有再次弹出语言选择或设置读取错误。未对设计稿执行写入。原生验收记录及产物哈希见 output/figma-registration/top-window-fix-acceptance.json。
