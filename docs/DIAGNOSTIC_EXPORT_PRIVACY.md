# 诊断日志导出过滤与反馈说明

日期：2026-10-17。版本：0.3.2。本次没有发布、推送或执行 MasterGo 打包。

## 原问题

原实现仅遮盖两个设置密钥字段，并主要递归处理日志的 data；自定义服务 URL 的 token、顶层 errorCode/message/detail 和其他自由文本存在导出遗漏。此前“自动隐藏密钥和图片”的实现不能支持“导出不含敏感内容”的笼统承诺。复现仅使用虚构数据，没有收集用户凭据。

## 过滤边界

`src/shared/diagnostics.ts` 是 UI 与主线程共用的轻量模块，旧路径保留转发，避免两套过滤规则漂移。无新增运行时依赖。

- 采集和导出均重新构造允许字段，不复制原始对象。只保留时间、版本、固定事件/操作/错误类别、耗时、有限的数量与 HTTP 状态等元数据。
- 未知命令统一为 OTHER，未知错误统一为 UNKNOWN_ERROR。自由错误文本、额外字段、任意嵌套载荷、服务地址（含域名、路径和参数）、密钥、图片、设计文字、图层名称/ID、会话标识和自定义输入不进入导出。
- 设置只保留少量布尔开关与固定主题/服务类别；不导出完整配置。系统 userAgent、platform 和语言指纹不导出。
- 问题描述与复现步骤单独提供，不混入日志。UI 合并主线程与界面数据后，下载函数在 JSON 序列化前再次执行同一过滤。
- 日志不自动发送；导出只生成本机下载。采集保持默认仅错误、详细模式可选；清空日志同时清空近期上下文，不清除设置或凭据。
- 新增排障字段需显式加入允许范围并覆盖隐私测试；不通过匹配几种密钥格式猜测任意文本是否安全。

该导出策略有意减少原始错误细节。需要更多信息时由用户单独描述，不能重新启用任意错误响应或请求正文导出。对外说明限定为上述明确排除项，不对用户自行提供的描述或截图作无敏感内容的承诺。

## 反馈说明

日志页、隐私页及反馈页已同步八语。中英支持说明见 [SUPPORT.md](SUPPORT.md)。截图和问题描述仍提醒先移除敏感内容，不要发送 API 密钥。
