# 380px 窗口适配

2026-10-16，Figma 独立工程 v0.3.1。用户已确认将默认窗口由 420×650 缩小至 380×650。

## 行为

- 主线程初次 showUI、浏览器测试页、恢复默认按钮、无效尺寸回退统一读取 `UI_SIZE`。最窄仍为 320px；用户拖动后的窗口尺寸及最小化前尺寸继续按原逻辑保留。
- 原公共样式、字号与输入控件尺寸保持。窄窗口允许标题、单选项、标签、页签和操作按钮换行。确认按钮保留 32px 最小高度，普通控件保留 28px 最小高度。
- 首页卡片按当前语言最长内容统一增高。380px 下中文、日文、韩文约 73px，英法西葡约 88px，德文约 106px；较长页面通过纵向滚动查看。两列宽度一致，标题不再与状态徽标争用单行。
- 文本填充、替换、图层清理、尺寸适配的结果表格在各自区域横向滚动，操作区留在表格外。滚动区可键盘聚焦，表头允许换行；长图层数据沿用原来的省略与 title 提示。
- 修复 320px 下确认弹窗的网格最小内容宽度，弹窗随剩余空间收缩；长明细换行，正文局部滚动。

## 验证范围

浏览器使用实际 ReferenceApp、实际样式和独立示例文档，隔离于用户的浏览器设置与真实 Figma 文档。首页和 10 个工具初始页面覆盖 8 种语言 × 4 种宽度（320/360/380/420px），共 352 组。页面横向溢出及关键按钮、标题裁切检测均通过。补充六种预览／结果状态 192 组、设置页与常规设置 64 组、确认弹窗 16 组，总计 624 组布局检查均通过。表格聚焦后按右方向键，局部 scrollLeft 达到 40px，页面仍宽 380px，操作区保持在表格外。原始度量与截图存于本机 `output/width380/`。

真实 Figma 已关闭旧实例并从 Development 重新运行。控制台读取到 `innerWidth=380`、`innerHeight=650`，正文与页面滚动宽度均为 380。首页宣传图正常；原有自定义字段可读取和展开，生成 20 条只读预览，表格与操作区可查看；最小化和恢复已实际操作。本轮未保存或删除宿主字段、未执行真实图层写入。八语完整矩阵来自浏览器；不将其宣称为八语真实宿主全功能验收。

## 启动与交付

本轮未增加资源、网络请求或初始化等待。宣传图仍在首页提交后读取，OCR 资源仍按需读取，未恢复已删除的行政区加载入口。窄窗口规则放在 `src/ui/reference-additions.css`，原公共样式基线不变。

最终构建体积、自动检查及注册目录一致性见本机 `output/width380/acceptance.json`。此任务不执行发布打包、版本递增或 GitHub 上传。
