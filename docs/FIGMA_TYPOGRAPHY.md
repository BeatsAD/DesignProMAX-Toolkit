# Figma 文字层级适配

> 后续一致性修复已按用户授权完成，见 [设计一致性实施记录](DESIGN_CONSISTENCY.md)。以下保留此前阶段的测量与宿主记录，不作为本次最终构建的验收结论。

2026-10-16，Figma 独立工程 v0.3.1。用户确认采用正文 11px／450、工具与分组标题 550、辅助说明 10px，并保持 380px 默认宽度。

## 实现

`src/ui/figma-typography.css` 在原参考样式和主题适配后加载。将普通字重变量设为 450，为语义标题、strong/b、字段标题、联系信息及主操作/危险操作恢复 550 字重；嵌套的文字标签同样获得强调字重，避免参考样式对每个后代强制指定普通字重而使标题内的 span 失去层级。

保留原有 10／11／12px 字号与行高，页面及工具标题仍为 12px；宣传图使用原有响应式大字，不压缩成普通界面字号。字体栈沿用 Inter 和系统回退，未新增字体文件或网络字体。450／550 是 CSS 请求字重，具体字形由当前字体及其支持的字重决定，不承诺不同系统下逐像素一致。

参考 `src/reference/ui/styles.css` 和记录的基线 SHA-256 均不变。颜色继续由 `figma-theme.css` 接入宿主语义变量；宽度、控件高度、保存行为、自定义字段与结果数据不变。
