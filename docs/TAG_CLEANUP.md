# 状态标签精简

2026-10-16，按用户确认的清单处理全部十个工具页面、帮助和消息公告。工具页面的 `StatusTag` 使用点由 37 处减至 10 处，其余保留异常、待核对、已插入、当前页面等有操作价值的信息。数字统计使用普通文字，不再使用成功色标签。

| 范围 | 最终行为 |
| --- | --- |
| 裁剪透明 | 移除按需读取／读取体积角标、PNG、可写入、未就绪；单图不显示数量，批量显示普通数量文字；保留失败、跳过、具体错误与重试能力 |
| 一键抠图 | 移除正常成功、对象类型和服务已配置标签；批量数量使用普通文字；未配置状态与去配置按钮保留 |
| 文本填充 | 移除默认规则、自定义字段总数标签；多条预览使用普通数量，预览失效保留正文警告 |
| 文本拆合 | 移除重复的当前模式和常态结果标签；多个拆分结果显示普通数量；不可执行原因与预览失效继续显示 |
| 尺寸适配 | 移除单选数量、已选策略、高可信度标签；多选数量使用普通文字；保留中低可信度、冻结和风险原因 |
| 文本识别 | 移除本地处理、按需加载、重复处理中、平均置信度及耗时／行数／编辑说明标签；原任务进度和具体低置信度行警告保留 |
| 图片分割 | 移除对象数、区域数、输出数量和固定格式的标题标签；保留已有的选择数／总数、待核对、已插入及错误原因 |
| 数据统计 | 移除全部页面／页面树及结果总量标签；统计正文总计、页面选择器和当前页面标记保留；380px 及以下筛选项改为两列，避免长翻译挤压 |
| 文本替换 | 移除条件选项数量标签；文本模式在列表选择栏显示一次已选数／总数，样式模式在结果标题显示一次普通选择统计 |
| 帮助 | 索引移除重复状态，详情保留需配置等状态和直达操作 |
| 消息公告 | 移除按分类第一条硬编码的“新”；保留未读圆点及当前版本 |

正常裁剪结果仍显示图层名称、图片预览、原尺寸、裁剪后尺寸、体积和写入操作。移除标签不影响勾选、禁用条件、写入、失败结果保留或撤销逻辑。共享 `StatusTag` 组件和已记录的 MasterGo 样式基线未修改；普通数量样式位于 Figma 适配样式中。
