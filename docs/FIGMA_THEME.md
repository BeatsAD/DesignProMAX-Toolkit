## 颜色来源

主线程继续使用 `figma.showUI(..., {themeColors:true})`。`src/ui/figma-theme.css` 将既有产品变量映射到 Figma 注入的 `--figma-color-*`，覆盖背景、面板、控件、正文、辅助文字、图标、边框、主色，以及悬停、按下、选中、禁用、成功、警告和错误状态。原 `src/reference/ui/styles.css` 及其基线哈希保持不变。

当插件显示模式与宿主一致时，使用实时宿主变量；宿主更新变量时 CSS 直接生效。手动选择与宿主相反的模式时，使用对应的内置基础色板，避免将浅色变量错误用于深色界面。宿主缺失个别变量和普通浏览器预览也有本地回退。内置回退不承诺与未来版本 Figma 的所有色值完全相同；同模式下的实时变量是正式宿主颜色来源。

透明棋盘沿用交错中性色，不修改图片像素；反馈二维码的白底保留，Logo 与宣传图片本身不重着色。

## 主题优先级与兼容

- 新配置默认 `system`，即跟随 Figma 的 `figma-light` / `figma-dark`；无 Figma 类的普通浏览器预览才使用系统配色偏好。
- 已存储的 `light` / `dark` 保持为手动选择，包括旧版基础设置中的主题。读取与首次启动不会改写旧配置。
- 顶部明暗按钮保持一次点击切换，切换后保存为手动浅色或深色。
- 设置中心 → 常规设置 → 主题模式提供“跟随 Figma／浅色／深色”，可恢复跟随。
- 保存失败时恢复先前偏好，显示原有错误反馈；不重建已就绪 UI，不重放业务操作。
- 宿主切换使用轻量 class 观察与 React 外部状态订阅，不发送保存请求，不重新读取配置，不改变当前输入或工具结果。

配置类型、默认值、保存校验和读取规范化均支持三种值；保持其他设置、自定义字段和布局的存储命名空间。
