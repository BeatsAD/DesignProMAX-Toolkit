# MasterGo 界面与交互保留约定

2026-10-16，适用于 DesignProMAX Toolkit Figma v0.3.1。

用户明确要求：沿用 MasterGo 的设计样式、风格、框架与交互。Figma 适配不构成重新设计界面的授权。v0.2.0 的绿色独立界面已退出正式入口。

## 保留基线

参考本机 MasterGo v1.0.48。原界面的 React 页面、组件和样式独立复制到 `src/reference/` 后单独维护；构建不导入父工程。`docs/mastergo-ui-baseline.json` 记录原样保留文件的 SHA-256，测试校验这些副本，包含公共样式、布局管理、主要工具样式、原 logo 与参考横幅。首页 Banner 已按用户授权拆为独立组件，HomePage 的原哈希和定制原因记录在 customizedFiles。

- 保留蓝白配色、明暗主题、字号、间距、卡片、面板、按钮、表单、反馈、确认框与过渡。
- 经用户后续确认，Figma 文字适配层将普通字重设为 450、强调字重设为 550，保留原有 10／11／12px 字号和 380px 默认宽度；参考样式及其基线不变，详见 `FIGMA_TYPOGRAPHY.md`。
- 默认窗口按精简后的首页改为 380×650；保留拖动调整尺寸、最小化/恢复、紧凑快捷栏及其独立布局。
- 保留首页布局管理、设置列表/子页、帮助、消息中心。
- 保留工具的字段展开、参数编辑、结果表格、勾选、预览、确认、局部反馈、取消操作与恢复路径。
- 图片分割沿用可视区域预览、坐标/宽高编辑、补框、拆分、合并及结果放大/下载。

按最新确认移除整个侧边栏、抽屉、遮罩和开关；Logo 移至顶部最左侧，工具页标题旁加入返回首页箭头。此项为用户明确授权的导航调整，保留其余页面与控件风格。后续另按用户反馈缩短默认高度，并统一首页卡片等高和内边距，详见 IMPLEMENTATION_STATUS.md。

仅按已确认需求变更：功能删除、尺寸适配名称与内容、语言选择、Figma 文案/宿主通信、反馈链接/二维码、版本仓库入口及服务授权说明。新增语言选择也使用原有模态框和按钮样式。

## 适配边界

`src/engine/reference-controller.ts` 承接原页面消息协议，转交独立 Figma 适配器。原页面不能因迁移而变成只有外观的按钮；设置保存、历史、诊断、布局和资源读取均需对应实现。

浏览器外层 `src/preview/workbench.tsx` 只承载插件 iframe 与示例画布；它的工具条与画布不是插件页面，不进入 Figma 生产 UI。iframe 默认实际内容区域为 380×650，避免边框改变内部断点或窗口恢复尺寸。

## 多语言维护要求

v0.3.1 已完成原页面八语界面、帮助、错误、确认和动态文案接入，详见 [多语言验收](LANGUAGE_ACCEPTANCE.md)。新增界面文案必须通过生产覆盖检查；不得只增加语言选择器或以英文回退代替其他语言。图层名、用户输入、字体和填充候选保持数据原值。

语言切换不替换原页面框架、控件或交互；首页插画按用户授权重新生成无文字版本，宣传文字使用可翻译的 HTML，新增样式用于语言选择、横幅文字层及后续确认的顶部导航调整，原公共样式文件保持字节一致。


2026-10-16 后续按用户明确授权增加 Figma 主题适配层：原公共样式保持字节一致，颜色通过独立 CSS 映射至宿主语义变量。新增默认跟随与手动覆盖优先级，保留布局、字号与尺寸，详见 [Figma 主题适配](FIGMA_THEME.md)。
