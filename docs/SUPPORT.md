# Support / 联系与支持

Support: **wenbinailab@gmail.com**

Use [GitHub Issues](https://github.com/BeatsAD/DesignProMAX-Toolkit/issues/new/choose) for ordinary bugs and feature requests. For security/privacy vulnerabilities, use the private email channel in [SECURITY.md](../SECURITY.md). Check [installation](INSTALLATION.md) for setup issues. Support is provided as available, without a guaranteed response time.

To report an issue, export logs from **Settings → Diagnostic logs** and attach the JSON file. Include your plugin version, Figma platform, steps to reproduce, expected result and actual result.

Diagnostic exports contain operational metadata such as operation types, known error categories, timestamps, durations and counts. They exclude API keys, service URLs, arbitrary error text, images and design text. Exporting downloads a file locally; it does not send it automatically. Detailed diagnostics can be enabled before reproducing an issue if more operational history is needed.

Describe the issue separately from the log file. Remove sensitive content from screenshots and your own description. Never send API keys.

反馈问题时，可在**设置中心 → 诊断日志**中导出日志，将 JSON 文件作为附件，并附上插件版本、Figma 平台、复现步骤、预期和实际结果。

普通缺陷和功能建议请使用 [GitHub Issues](https://github.com/BeatsAD/DesignProMAX-Toolkit/issues/new/choose)。安全及隐私问题请按 [SECURITY.md](../SECURITY.md) 私下联系；安装问题先看[安装指南](INSTALLATION.md)。支持按维护能力提供，不承诺固定响应时间。

导出日志仅包含操作类型、已知错误类别、时间、耗时和数量等排障信息，不包含 API 密钥、服务地址、自由错误文本、图片或设计文字。导出只在本机下载文件，不会自动发送。需要更多操作记录时，可先开启详细诊断，再复现问题。

问题描述请与日志分开提供。截图和自行填写的描述请先移除敏感内容，不要发送 API 密钥。
